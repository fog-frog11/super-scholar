# Super Scholar V2.1

This maintenance release addresses two issues reported on Windows and during venue recommendation.

## Fixed

1. **CCFDDL timezone compatibility on Windows**
   - Adds the `tzdata` runtime dependency.
   - Supports AoE, PT, UTC offsets, and explicit IANA timezone names such as `America/Los_Angeles`.
   - A single unresolved timezone no longer aborts the entire conference catalog parse.

2. **Recommendation loading feedback**
   - The numeric percentage still advances only when a real pipeline stage completes.
   - Continuous orbit/scan/shimmer animation remains active while a network request is pending.
   - A real elapsed-seconds counter makes long upstream waits visible.
   - The current stage is visually marked as processing.

## Research Profile clarification

V2.1 still uses the deterministic local Research Profile baseline. It does not yet use an LLM, OCR, or a vision model. PDF figures are not visually interpreted. See README.md for exact current capabilities.
