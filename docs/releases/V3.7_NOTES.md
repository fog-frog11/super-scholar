# Super Scholar V3.7.0 — CS semantic venue recommendation

## Scope

V3.7 intentionally implements only the current CS MVP:

```text
Upload research → Understand research → Recommend venue → Compare / select venue
```

It does not add venue-paper RAG, manuscript rewriting, or cross-discipline ranking.

## Implemented

### Visual evidence V2

- PDF page renders are emitted before embedded PDF image blocks.
- AI vision selection prioritizes coherent page renders.
- Profile UI hides raw PDF image fragments when coherent visual artifacts exist.
- RT-DETR regression PDF produces seven coherent page-render visual artifacts before internal fragments.

### Evidence presentation V2

- Raw `ev_material_<uuid>...` IDs remain internal grounding keys.
- UI maps evidence to human labels such as `论文 · p.5`, `代码 · file.py`, and `结果 · Sheet1`.
- Raw IDs remain available in tooltips/diagnostics without cluttering the research profile.

### Recommendation engine V2

- Recommendation execution moved to the backend.
- CCF/CCFDDL construct the CS candidate universe.
- OpenAlex semantic search retrieves research-similar works.
- Similar-work publication Sources are aggregated into direct venue evidence.
- Research Match is dominated by semantic venue evidence; CCF area and venue-name lexical overlap are weak priors only.
- OpenAlex outage uses an explicitly low-confidence fallback capped so same-area venues cannot recreate the former `72` tie.
- Preferred CCF and CORE ranks are ordinal (A > B > C / A* > A > B > C).
- Required unknown remains ineligible; Preferred unknown is neutral.
- Closed conference editions are not current submission targets.
- Comparison UI exposes semantic evidence and avoids claiming a unique winner for near-ties.

### Venue data model

- Journal identity no longer includes mutable CCF rank/category.
- Conference series identity is separated from edition identity.
- Full CCFDDL `timeline[]` is preserved.
- Conference CCF rank/category are overlaid from official CCF pages when available; CCFDDL remains the deadline/location/CORE source.

## Regression checks

The RT-DETR paper is used as a semantic sanity case. With deterministic mocked OpenAlex evidence, a CVPR candidate scores strongly above AAMAS / ALT / COLING / FG even though all may share the broad CCF-AI category. The old `same CCF AI → Research Match 72` behavior is explicitly covered by tests and cannot be reproduced by the fallback formula.
