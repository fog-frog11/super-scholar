# Super Scholar V3.5

## UI
- Rebuilt switches with fixed track/thumb geometry and accessible `role=switch`.
- Removed sticky/floating connection-diagnostics card. It now stays in normal document flow.

## Project route recovery
- Project layouts now attempt a direct backend recovery when the persisted browser store does not yet contain the requested project.
- Recovery restores material metadata and extracted text where available.
- Missing/offline states are explicit and offer retry + project-list actions.
- Frontend dev/build scripts clear stale `.next`/`.turbo` route manifests before startup to avoid dynamic-route 404s after replacing an existing installation in place.
