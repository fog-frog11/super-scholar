# Super Scholar V3.11.0

## Scope

This release completes the current computer-science MVP recommendation stage after upload/research understanding. It does not add manuscript rewriting or venue-style RAG.

## Journal metadata

- OpenAlex Source public OA/DOAJ/APC/2yr-mean-citedness fields are parsed and attached only after conservative Source identity resolution.
- APC USD is converted to CNY only with a live ECB EXR reference observation; conversion provenance and date are retained.
- Clarivate Web of Science Journals API is an optional entitled source for WoS edition, JCR quartiles, JIF and JCI. Its key is encrypted separately in scholarly settings.
- OpenAlex 2yr mean citedness is never treated as JIF.
- Review speed remains unavailable unless a future publisher-specific verified adapter is implemented. Preferred missing review metadata is N/A, not fake “pass” or repeated Unknown.

## Evidence UX

- Global OpenAlex semantic results and venue-conditioned OpenAlex results keep all works returned by the backend run.
- The UI shows 5 by default and expands to all persisted works.
- Semantic Scholar evidence follows the same expand-all behavior.

## Validation

See automated tests for OpenAlex metadata parsing, ECB FX derivation, Clarivate JIF/JCR parsing, Preferred-vs-Required missing-metadata semantics and full evidence retention.
