# Super Scholar V3.8.0 notes

This release focuses only on the current CS MVP chain: upload research → understand research → recommend venues → user selects.

## Recommendation changes

- CCF/CCFDDL is no longer the candidate universe. OpenAlex Sources found through semantically related works are merged into the candidate pool; unmatched journal/conference series are retained as `OpenAlex discovery` candidates with unknown actionable edition metadata.
- OpenAlex Works parameter uses `per_page`; Source hydration is batched and optional.
- OpenAlex work topics keep stable Topic IDs/scores; Source topics are used for source-topic cosine fit.
- Added deterministic CS subfield scope model (vision, medical imaging, ML, NLP, robotics, multi-agent, DB/IR/mining, security, systems, SE, networks, theory, graphics, multimedia, HCI, speech, bioinformatics, efficient AI).
- Generic “agent” is not a multi-agent trigger.
- Manuscript bibliography is extracted from `References` / `Bibliography` only and contributes a 12% community prior. This prevents accepted-paper front-matter watermarks from leaking the ground-truth venue.
- Related-paper venue evidence uses absolute saturation: one direct hit is useful but cannot become 100 simply because it is the only hit.
- Missing Source-topic metadata is omitted and weights are renormalized. Unknown is never silently treated as a mismatch.
- Research Match weights when evidence is available: direct related-paper venue 30%, OpenAlex Source topics 30%, CS scope 25%, manuscript References 12%, CCF area 3%.
- OpenAlex-unavailable fallback: CS scope 65%, References 30%, CCF area 5%, capped at 78.
- Final ranking uses 84% Research Match + 16% user preference fit.
- Per-type Top-N is now enforced exactly; backend no longer returns `2×TopN` eligible results while the UI claims a maximum.
- Recommendation and comparison pages expose the individual evidence dimensions instead of the old venue-name lexical signal.

## Regression checks

- RT-DETR / object-detection profile: CVPR must outrank AAMAS/COLING/ALT/FG.
- BRDG surgical segmentation profile: CVPR/MICCAI/ECCV must outrank AAMAS/COLING/ICRA even when there is no direct OpenAlex source hit.
- “three cooperative agents” must not create a Multi-Agent Systems match.
- One unrelated direct OpenAlex venue hit must not override strong scope + bibliography evidence.
- Reference-section extraction must ignore a front-matter “This CVPR paper…” watermark.
